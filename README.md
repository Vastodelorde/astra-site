# astra-site

Статична копія головної сторінки astra.in.ua (навчально-демонстраційна, без бекенду).

Типографіка: **Wix Madefor Display** (заголовки) + **Inter** (основний текст), задані через CSS-змінні `--font-head` / `--font-body`.

## Структура
- `index.html` — сторінка (генерується з `build.mjs`).
- `css/base.css` — уся верстка й кольори; шрифти підключаються лише через змінні.
- `assets/` — локальні іконки, логотип, банери.
- `build.mjs` — генератор `index.html`.
- `serve.mjs` — мінімальний статичний dev-сервер.

## Запуск
```bash
node serve.mjs       # http://127.0.0.1:8099
# або
node build.mjs       # перегенерувати index.html
```

Шрифти тягнуться з Google Fonts (потрібен інтернет).
