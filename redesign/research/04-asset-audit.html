04 · Аудит візуальних ассетів

Інвентаризація наявних бренд-ассетів, вердикт по трьох командних фото з рекомендаціями кропу та кольорокорекції, і чернетковий перелік зображень на генерацію — вхід для промпт-райтера.

1Наявні бренд-ассети /assets

12 файлів. Логотип векторний і чистий; іконки месенджерів — дублі у двох стилях (монохром + кольорове коло), що треба уніфікувати.

Логотип і фавікон

logo.svg
SVG, 889×189, monochrome #FFFFFF. Знак «А-ракета» + леттеринг «АСТРА». Single-path, fill-rule. Контурний, без тексту слогана.
Зберегти · база
favicon.ico
ICO, 256×256, 12 КБ.
Зберегти
Зауваги по логотипу. Файл — суцільно білий (для темного навбару це ідеально). Для світлих секцій і друку потрібна navy-версія того ж шляху (просто заміна fill на #0e1b33) — її в наборі немає. Також бракує: (а) компактного знаку-марки без леттерингу (іконка-ракета для favicon/app/соцмереж), (б) горизонтального lockup зі слоганом «Сузір'я цифрових послуг» — на банері з фото №1 слоган набраний окремим жирним гротеском, але як SVG-lockup його немає.

Висновок по іконках: набір розрізнений — частина монохромна, частина у фірмових кольорах платформ, частина перефарбована в астрівський блакитний (#22a6e6/#25b2f7). Telegram існує у 3 версіях, Viber у 2. Для серйозного navy-тону рекомендую єдиний монохромний line-набір (один stroke-стиль, viewBox 24×24), що в навбарі/футері фарбується через currentColor у navy або white. Кольорові «brand-circle» версії лишити тільки для контактних CTA-кнопок (Telegram/Viber «напишіть нам»), де впізнаваність платформи важлива.

Фірмовий блакитний підтверджено ассетами: повторюваний #22a6e6 / #25b2f7 — це і є той «блакитний вторинний» з брифу. Можна зафіксувати як --blue токен. Червоного у наявних ассетах немає взагалі — акцентний --red вводиться вперше і має лишатися дозованим.

2Командні фото /materials/team

3 кежуальних кадри з тимбілдингу. Всі — на холодному похмурому світлі, що насправді грає на руку navy-тону: мінімум теплих відтінків, легко загнати в корпоративну гаму.

Фото A — 7 людей з банером «Сузір'я цифрових послуг»
726018354…_n.jpg · 960×1280 · 130 КБ · портрет (3:4)
Зміст
Сімка співробітників у фірмових поло «АСТРА» тримає білий банер з логотипом і слоганом. Карпатський фон: зелена гора, хмарне небо, ззаду банер «35 years». Найрепрезентативніший кадр — у ньому читається і бренд, і слоган, і люди.
Орієнтація / якість
Вертикаль 3:4, різкий, добра деталізація, рівний горизонт. Небо пересвічене й пласке — головна вада.
Рекоменд. кроп
Лишити вертикаль для мобільного блоку «Про команду». Для десктоп-секції — кроп 4:3 або 16:9 по групі (зрізати верхні ~30% порожнього неба та нижній мокрий асфальт), банер з логотипом тримати в кадрі.
Де на сайті
Про компанію → блок «Команда / Культура»; вторинно — невеликий вставний кадр біля бренд-лінії «Сузір'я цифрових послуг» (бо слоган фізично в кадрі).
Кольорокорекція
Підняти контраст, відновити небо (recover highlights / легкий градієнт-фільтр зверху), прибрати зеленаво-сірий каст балансом білого в холод. Зверху accent-secondary навіть бажаний. Для герметичності тону — м'який navy duotone-оверлей 8–12% або градієнт #0e1b33→прозорий знизу під підпис.
Вердикт
Придатне як ключове team-фото.
Фото B — велика групова (~50 осіб) з прапором «АСТРА»
683603188…_n.jpg · 2048×1536 · 598 КБ · ландшафт (4:3)
Зміст
Уся команда на корпоративі: ~50 людей у різному (від суконь до casual) на майданчику перед лісом, у центрі — синій прапор з логотипом. Демонструє масштаб компанії та «людський» бік.
Орієнтація / якість
Горизонталь 4:3, висока роздільність (2048px) — добре тягне у full-width. Світло пласке, похмуре; обличчя дрібні (загальний план).
Рекоменд. кроп
Панорамний кроп 21:9 / 16:9 по людях (зрізати порожнє небо зверху та тріщину асфальту знизу). Підходить як широка фонова стрічка.
Де на сайті
Про компанію → секція-роздільник «Команда» на повну ширину (фон під заголовок/цифри), або footer-CTA «Приєднуйтесь / Вакансії». Як hero не рекомендую — обличчя дрібні, банер «РВісіВ» з фото A тут відсутній.
Кольорокорекція
Той самий рецепт: +контраст, прибрати сірий каст, холодний баланс. Через дрібні обличчя сюди впевнено лягає темний navy-градієнт-оверлей (40–60%) з текстом поверх — кадр стає атмосферним тлом, а не самостійним фото. Прапор лишити читабельним.
Вердикт
Вторинне — фон-роздільник під оверлеєм.
Фото C — 8 інженерів у серверній (ЦОД)
517413036…_n.jpg · 1536×2048 · 580 КБ · портрет (3:4)
Зміст
Технічна команда у вузькому «гарячому коридорі» між чорними серверними стійками, кабель-канал зверху, всі показують «клас». Найцінніший кадр для B2B/інфраструктурного меседжу — реальний дата-центр, реальні люди, поло «АСТРА».
Орієнтація / якість
Вертикаль 3:4, висока роздільність, але складне змішане світло: теплі лампи зверху + холодні стійки, помітний шум у тінях, легка «жовтизна».
Рекоменд. кроп
Лишити вертикаль для картки/портретного слоту. Альтернатива — кроп 4:5 по групі. Стійки по краях навмисно лишити — вони дають «коридорну» глибину ЦОД.
Де на сайті
Напрям «Хмара / ЦОД» (ілюстрація «своя інфраструктура, свої люди»), лендінг БІЗНЕС (довіра до техкоманди), блок «Про компанію → Інфраструктура». Найсильніший аргумент-фото для B2B.
Кольорокорекція
Прибрати теплу жовтизну (зсув WB у холод/нейтраль), зменшити шум у тінях, підняти мікроконтраст на стійках. Кадр сам по собі майже navy (чорні стійки + сині поло) — достатньо легкого #16294a teal-навісу 10–15% для єдності. Не перетемнювати — обличчя мають лишатись.
Вердикт
Сильне — ключове фото для ЦОД/B2B.
Спільне по всіх трьох: єдиний пресет кольорокорекції (холодний WB, +контраст, легкий navy-duotone/градієнт) зведе різнопланові кежуальні кадри в один серйозний дорослий ряд. Усі три — реальні, без стоковості; це перевага, її варто зберегти, не «вилизуючи» в глянець. Жоден з трьох не годиться як головний hero сайту (всі — про команду, не про послугу) — hero доведеться генерувати.
