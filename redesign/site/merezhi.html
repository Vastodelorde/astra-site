Піринг

Піринг (від англ. «peering») – це процес прямого обміну інтернет-трафіком між двома або більше мережами. Основною метою пірингу є оптимізація маршрутизації даних, зменшення затримок і підвищення швидкості передачі інформації. Інтернет-провайдери використовують піринг для зниження витрат на передачу даних через треті сторони, забезпечуючи при цьому більш якісне та стабільне з'єднання для своїх клієнтів.

Піринг відбувається на спеціальних платформах, відомих як піринг-пункти або інтернет-обмінні точки (IXPs). Існують два основних види пірингу:

Публічний піринг

На загальнодоступних платформах

Багато провайдерів підключені до одного центрального комутатора.

Приватний піринг

Прямі з'єднання

Через прямі з'єднання між двома провайдерами, без використання загальнодоступних комутаторів. Дорожчий, але ефективніший.

Послуга піринг надається виключно юридичним особам та операторам зв'язку. Для подачі заявки на приватний піринг, пишіть на нашу пошту. Інформацію про наші піринг-пункти та про нашу АС можна подивитись на сайті.

Послуги NOC

Налаштування та обслуговування мережевого обладнання нашими інженерами: маршрутизація, резервування каналів, захист периметра та віддалений доступ. Для бізнес-абонентів та корпоративних клієнтів.

  • Firewall на маршрутизаторі/сервері
  • dst-nat (port-forwarding) на маршрутизаторі
  • CapsMan — централізоване керування точками
  • Mesh — безшовна бездротова мережа
  • Dual-WAN резервування на маршрутизаторі/сервері
  • Dual-WAN балансування на маршрутизаторі/сервері
  • BGP/OSPF на маршрутизаторі/сервері
  • LACP/LAGG/BOND балансування/резервування (за умови підтримки обладнанням протоколів агрегації)
  • IPv6 на маршрутизаторі/сервері
  • VPN-сервер на маршрутизаторі/сервері
  • VPN-клієнти на маршрутизаторі/сервері/ПК
  • Об'єднання офісів та два одночасних підключення
500 грн/год тарифікація додаткових мережевих налаштувань (юр.), не менше 1 год

СКС · Wi-Fi · Mesh NEW/уточнити

Проєктування та монтаж структурованих кабельних систем, розгортання бездротових мереж Wi-Fi і безшовних Mesh-рішень для офісів, ЖК та об'єктів бізнесу.

СКС

Структуровані кабельні системи: проєктування траси, прокладання, маркування, патч-панелі та розетки.

Wi-Fi

Розгортання бездротових мереж з покриттям під площу та кількість пристроїв, керування через CapsMan.

Mesh

Безшовна бездротова мережа без розривів з'єднання під час переміщення між точками доступу.

ВОЛЗ · оптичні лінії NEW/уточнити

Прокладання та обслуговування волоконно-оптичних ліній зв'язку для з'єднання об'єктів, підключення майданчиків та побудови магістральних сегментів мережі.

Проєктування траси

Розрахунок траси, вибір технології (FTTB / PON), узгодження з умовами об'єкта.

Монтаж та зварювання

Прокладання оптичного кабелю, зварювання волокон, монтаж кросів та оптичних боксів.

З'єднання майданчиків

Оптичні лінії між офісами, корпусами та виробничими майданчиками компанії.

Енергонезалежність

Інфраструктура з резервним живленням для роботи навіть під час відключень світла.

Сценарії для бізнесу та ОСББ

Типові завдання, які наша інженерна команда вирішує для корпоративних клієнтів, ЖК та об'єднань співвласників.

Об'єднання офісів

VPN між майданчиками, два одночасних підключення та резервування Dual-WAN для безперервної роботи.

Мережа для ЖК та ОСББ

СКС у будинку, Wi-Fi у спільних зонах та оптична лінія до кожного під'їзду.

Піринг для операторів

Публічний та приватний піринг для операторів зв'язку: менша затримка, вища стабільність, нижчі витрати.
