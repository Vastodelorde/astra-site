Налаштування підключення до Інтернету

Оберіть тип підключення вашого тарифу. Якщо не впевнені, тип з'єднання підкаже оператор підтримки.

Підключення PPPoE

Налаштування типу підключення PPPoE. Відеоінструкції для:

  • Роутер TP-Link TL-WR841N.
  • ПК з Microsoft Windows 8 та 10.
  • ПК з Linux Ubuntu.
Підключення DHCP

Налаштування типу підключення DHCP. Відеоінструкції для:

  • Роутер TP-Link Archer C64.
  • Роутер Sercom TIM.

Як встановити АСТРА TV на ваш пристрій

Оберіть свій пристрій і виконайте кроки. Для приставок і телевізорів рекомендуємо підключення кабелем.

Комп'ютер (Windows)
  1. Завантажте програму за посиланням: завантажити
  2. Запустіть файл та виберіть одну з доступних мов встановлення.
  3. Натисніть «Далі >».
  4. За потреби встановіть відмітку «Створити Ярлики на робочому столі» та натисніть «Далі >».
  5. Підтвердіть шлях встановлення та додаткові опції натиснувши «Встановити».
  6. Дочекайтесь завершення встановлення.
  7. Натисніть «Готово».
  8. Виберіть одну з доступних мов інтерфейсу.
  9. Натисніть «Закрити».
  10. Після ознайомлення з довідковою інформацією натисніть «Закрити».
  11. Насолоджуйтесь переглядом улюблених телеканалів.
Samsung Smart TV

Достатньо встановити застосунок Astra TV або SmartUp з магазину застосунків Smart HUB. Якщо неможливо — дотримуйтеся інструкцій:

  1. Пультом зайдіть в Apps.
  2. В пошуку введіть Astra TV.
  3. Виберіть та встановіть Astra TV.
  4. Відкрийте або знайдіть серед встановлених.
  5. При першому відкритті виберіть мову інтерфейсу.

УВАГА! При встановленні через сервер синхронізації застосунків усі не заводські застосунки буде видалено.

Tizen (2015-2016)

  • встановити IPTVPORTAL з Smart HUB.

H-series (2014): під користувачем developer

  • Menu → Smart Hub → Обл. зап. Samsung → Вхід ID: develop, Пароль: 11111111 → Увійти.
  • Додати IP: Smart hub → повний Smart Hub → утримати ОК на застосунку → IP Setting → IP 193.93.216.13 → утримати ОК → Start User App Sync.

F-series (2013): під developer

  • Smart hub → Menu → Функцію Smart → Обл. зап. Samsung → Ел.п.: develop, Пароль: sso1029dev! → Запам'ятати → Увійти.
  • Додати IP: Smart hub → Додаткові застосунки → Парам → IP Setting → IP 193.93.216.13 → Парам → Start App Sync.

E-series (2012): під developer

  • Smart hub → червона (А) → Обл. зап. Samsung: develop, Пароль: 111111 → увійти.
  • Додати IP: Tools → Налаштування → Розробка → прапорці ОК → Налаштування IP-адреса серв. → IP 193.93.216.13 → Синхронізація застосунку користувача → перезавантажити телевізор.

На деяких ТВ застосунок видаляється при вході в SmartHub — достатньо вийти з режиму develop.

iOS (iPhone, Apple TV)
  1. Підключіть Apple TV або iPhone до Інтернет (приставку рекомендуємо кабелем).
  2. Відкрийте App Store та уведіть в пошуку Astra TV.
  3. Отримати.
  4. Приємного перегляду!
Android
  1. Підключіть телевізор до Інтернет (рекомендуємо кабелем).
  2. Відкрийте Google Play Store та натисніть «Увійти».
  3. Введіть дані входу до Google.
  4. У пошуку введіть Астра TV.
  5. Виберіть додаток та натисніть «Установити».
  6. Натисніть «Відкрити».
  7. Натисніть «Дозволити».

Встановлення із Flash-накопичувача

  1. Завантажте файл AstraTV для неофіційних приставок на flash.
  2. Підключіть flash до приставки та відкрийте файловий менеджер.
  3. Перейдіть до USB.
  4. Оберіть додаток на flash.
  5. Натисніть "Install".
  6. Натисніть «Open».
  7. Додаток розміщено у встановлених програмах.

Корисні можливості для абонентів

Призупинення послуг

Якщо ви їдете у відпустку чи відрядження на тривалий термін, і не хочете втратити залишок коштів, що є на рахунку, то послугу Інтернет від Астри можна просто призупинити. Доки послугу призупинено, кошти з особового рахунку не списуються. Призупинити послугу можна на строк від одного тижня до двох місяців. Призупинити послуги Ви можете через Особистий Кабінет.

Активація безкоштовно один раз на місяць, далі 5 грн.

В особистому кабінеті →

Кредит

У Вас закінчились кошти на рахунку, а доступ до Інтернет потрібний зараз і вже? Не варто хвилюватись, скористайтесь послугою «Кредит» і залишайтесь на зв'язку. Активувати послугу можна на персональній сторінці в «Особистому кабінеті». Вартість активації послуги «Кредит» для фізичних осіб складає 3 грн. Термін дії послуги складає 3 дні від моменту активації. Юридичні особи можуть замовити послугу кредит телефоном у оператора техпідтримки, вартість 10 грн, термін дії 3 дні.

Рекомендація для власників роутерів: в деяких випадках після активації послуги «Кредит» необхідно перезавантажити роутер (від'єднати від мережі 220В на 10 сек).

Безпечний DNS

Функція «Безпечний DNS» дозволяє захиститися від ненадійних сайтів, на яких можуть бути віруси, фішинг та інші загрози. Ми використовуємо спеціальні DNS-сервери, які фільтрують шкідливі та ненадійні ресурси. Функція вже активована. Якщо у вас обрані DNS примусово, змініть налаштування DNS на:
